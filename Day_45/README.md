## Main topics

- Constructing informative features from existing columns
- Combining and transforming raw variables
- Splitting a compound column into useful components
- Domain-informed feature engineering
- Feature construction inside a reproducible workflow

---

## Learning objectives

1. Distinguish feature construction from feature selection.
2. Build new variables such as family size or extracted text components.
3. Explain how a constructed feature changes the hypothesis space.
4. Assess whether a new feature is useful rather than merely available.
5. Connect construction decisions to leakage and deployment.
