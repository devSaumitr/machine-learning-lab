## Main topics

## Learning objectives

1. Explain why linear regression is unsuitable for class probabilities.
2. Derive the perceptron update and identify its limitations.
3. Interpret the sigmoid output as a probability.
4. Connect log loss to maximum likelihood.
5. Train logistic regression via gradient descent.
