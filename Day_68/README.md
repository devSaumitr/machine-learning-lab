## Main topics

## Learning objectives

1. Distinguish stacking from voting and blending.
2. Explain why the meta-learner must use out-of-fold predictions.
3. Describe the data flow from base models to meta-model.
4. Compare blending with stacking.
5. Recognise and prevent meta-feature leakage.
