## Learning objectives

1. Explain how gradient boosting corrects the previous ensemble's residuals.
2. Describe the role of the learning rate as shrinkage.
3. Trace one boosting iteration by hand.
4. Compare gradient boosting with AdaBoost and random forests.
5. Recognise overfitting risks and tuning controls.
