## Main topics

- Unsupervised clustering and the k-means objective
- Centroid initialisation and assignment/update steps
- Within-cluster sum of squares and the elbow method
- Cluster interpretation
- Limitations and practical considerations

---

## Learning objectives

1. Explain the assignment and update steps of Lloyd's algorithm.
2. Interpret WCSS and the elbow plot.
3. Choose the number of clusters with evidence, not only the plot.
4. Interpret cluster centroids in feature space.
5. Recognise scale, initialisation, and shape limitations.
