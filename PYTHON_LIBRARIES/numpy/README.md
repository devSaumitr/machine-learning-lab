# NumPy Learning - Machine Learning Lab

A collection of Python scripts exploring **NumPy** — the foundational library for numerical computing in Python and a prerequisite for machine learning.

## Repository

**Repo:** [machine-learning-lab](https://github.com/devSaumitr/machine-learning-lab)
**Branch:** `main`
**Remote:** `origin` → `https://github.com/devSaumitr/machine-learning-lab.git`

## Workflow

```
Local Machine (Windows)
        │
        │  git add .
        │  git commit -m "message"
        │  git push origin main
        ▼
  GitHub (origin/main)
        │
        │  git pull origin main
        ▼
Local Machine (synced)
```

### Day-to-Day Steps

1. **Write / edit scripts** locally in this folder
2. **Stage changes** → `git add .`
3. **Commit** with a clear message → `git commit -m "add topic"`
4. **Push** to GitHub → `git push origin main`
5. **Pull** before starting new work → `git pull origin main`

## Files

| File | Topic |
|---|---|
| `basics.py` | Array creation, dtypes, basic operations |
| `attributes.py` | Array attributes (shape, ndim, dtype, size) |
| `indexing and slicinig .py` | Indexing & slicing arrays |
| `arrayoperations.py` | Array math operations |
| `arrayopr_scalar.y.py` | Scalar operations on arrays |
| `vectoropr.py` | Vector operations |
| `broadcasting.md` | Broadcasting rules & examples |
| `stacking.py` | Stacking arrays (vstack, hstack) |
| `splitting.py` | Splitting arrays |
| `set_fn.py` | Set functions on arrays |
| `graph.py` | Graph / plotting with NumPy |
| `others.py` | Miscellaneous NumPy functions |
| `othe.py` | Additional NumPy notes |
| `trickss1.py` | NumPy tricks & tips |
| `advanced.py` | Advanced NumPy concepts |

## Getting Started

```bash
# Clone the repo
git clone https://github.com/devSaumitr/machine-learning-lab.git

# Navigate to numpy folder
cd machine-learning-lab/PYTHON_LIBRARIES/numpy

# Run any script
python basics.py
```

## Requirements

- Python 3.x
- NumPy (`pip install numpy`)
